# 올라 개발 요약

## 서비스 목표

동반자가 있는 모든 산행에 AI 안전 진단을 제공한다. 날씨·코스·재난위험·일몰 데이터를 종합해 추천(초록)/주의(노랑)/비추천(빨강) 3단계 안전 등급을 실시간으로 산출하고, 산행 중 세이프 링크로 보호자와 위치를 공유한다.

## 추천 점수 스코어링 (실제 구현)

`backend/recommendations/services.py` 기준.

### 4개 원점수

**기상 안전도** (0~100)
- 100점 시작, 강수/풍속/기온 조건별 감점
- 복합 위험(비+강풍, 영하+강수, 폭염+무풍) 추가 감점

**체력 적합도** (35~100)
- 사용자 경험·강도·컨디션으로 target 난이도 산출
- `max(100 - gap×28 - 고도상승m/25, 35)`

**접근성** (20~100)
- haversine 거리 기반: `max(100 - distance_km×3.2, 20)`
- 사용자 설정 최대 거리 초과 시 추가 감점

**시간 적합도** (15~100)
- 코스 소요시간 vs 가용 시간 비교
- 희망 시간 ±버퍼 범위 이탈 시 감점 (취약자 동반: 버퍼 ±15분, 일반: ±30분)
- 일몰 여유 부족 시 -10~-45점

### 가중 합산 (목적·동반자별 동적 가중치)

| 조건 | 체력 | 기상 | 시간 | 접근성 |
|------|------|------|------|--------|
| 취약자 동반 | 0.45 | 0.25 | 0.25 | 0.05 |
| 힐링 | 0.25 | 0.35 | 0.15 | 0.25 |
| 운동 | 0.40 | 0.25 | 0.15 | 0.20 |
| 기본 | 0.35 | 0.30 | 0.15 | 0.20 |

### 보너스·페널티

- 산 이름 일치: +45 / 재난위험 고위험: -6/개 / 혼잡도: crowding×-8
- 목적 보너스: healing +10~18, workout +12, view +10
- 이동수단 보너스: 대중교통+근거리 +6, 차량 +5
- 데이터 품질: 좌표 없음 -28, 거리 <0.3km -35, 일반명 -18

### 안전 등급 (룰 기반, 점수와 독립)

**비추천**: 강수≥10mm, 풍속≥8m/s, 일몰 여유<30분, 산불 very_high, 취약자+hard 난이도 중 하나라도 해당

**주의**: 빨강 없음 + (취약자: 노랑플래그≥1 OR 기상<85 OR 체력<75 OR 시간<75) / (일반: 노랑플래그≥2 OR 기상<80 OR 체력<65 OR 시간<70)

**추천**: 위 조건 모두 해당 없음

### 정렬 기준

안전 등급(recommend>caution>not_recommended) → total 점수 → 검색 산 이름 일치 코스 상단 재배치
